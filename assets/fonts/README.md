# Fonts

## Racing / general
- **LARAZ Regular.ttf** – primary font (body text, headings)
- **LARAZ Light.ttf** – light weight (`theme.fontFamily.light`)
- **Swish-Regular.ttf** – accent display
- **Polygon-Regular.otf** / **Polygon-Italic.otf** – results accents

## LMS / football (Bai Jamjuree)
- **BaiJamjuree-ExtraLight.ttf** – `theme.fontFamily.baiExtraLight`
- **BaiJamjuree-Light.ttf** – `theme.fontFamily.baiLight`
- **BaiJamjuree-Regular.ttf** – `theme.fontFamily.bai`
- **BaiJamjuree-Medium.ttf** – `theme.fontFamily.baiMedium`
- **BaiJamjuree-SemiBold.ttf** – `theme.fontFamily.baiSemiBold`
- **BaiJamjuree-Bold.ttf** – `theme.fontFamily.baiBold`

Loaded in `app/_layout.tsx`. Prefer the named weight over `fontWeight` with Regular.
